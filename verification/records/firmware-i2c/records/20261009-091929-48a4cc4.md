- **Claim**: Four **committed** I2C controller programs --
  `firmware/asm/i2c_fast_sr.asm`, `i2c_std_sr.asm` (EXACT: no pin-dependent
  branch) and `i2c_fast_sr_poll.asm`, `i2c_std_sr_poll.asm` (SCL-polling,
  clock-stretch tolerant), images under `firmware/build/` -- loaded over the
  real serial load-phase pins onto `tt_um_2amlogic_protocol_emulator` and
  executed by `rtl/protocol_core.v`, drive **START, 0xA0 (0x50 W) + ACK, 0x5A
  + ACK, repeated START, 0xA1 (0x50 R) + ACK, one byte read from the
  peripheral, controller NACK, STOP** in both speed grades. The independent
  model `verification/reference_models/i2c.py` (unchanged) judges every UM10204
  Table 10 minimum met **in exact cycles, t_SU;STA included**, and decodes
  `data=[0x5a, 0xa1, 0xb4], acks=[True, True, True, False]`. This is issue #92
  and closes unmet-reason (a) of `spec/gap-to-submission.md` row 12 (t_SU;STA
  unexercised; no read direction; no clock-stretch handling) -- the
  controller-read and stretch dimensions of `spec/verification-plan.md` section 4.
  **Scope boundary.** Controller role, one write byte then one read byte, both
  grades, Icarus, against a bench-composed wired-AND bus. No clock frequency
  (all kHz are arithmetic at row 4's unconfirmed clock), no silicon-true
  open-drain (`uio_oe` fixed to 0; DR 0008 / #75 owns it), no multi-byte
  burst, no 10-bit addressing. The controller does not branch on the ACK bits
  it samples (the transfer is scripted; the model grades the ACKs on the wire).
  Row 12 stays **unmet** on reason (b).
- **Design provenance**: `rtl` -- `src/tt_um_2amlogic_protocol_emulator.v`,
  `rtl/protocol_core.v`, `rtl/protocol_program_memory.v` @ `48a4cc4`,
  **unchanged by this issue** (no I2C peripheral, no ISA change). Firmware:
  the four `.asm` files above @ `48a4cc4`+this change, written by

  and that the committed `.asm` equals the generator's output). Assembled by
  `firmware/tools/asm.py` (DR 0003) into the hashed image/report pairs.
  **Program-store fit**: `_sr` 131/256 words, `_sr_poll` 171/256 words. The
  earlier unrolled write-only programs used 181 words; these fit because the
  bit loops use a counter. With four registers the loop keeps R0 = ~byte
  (after 8 shifts it is 0, which the AND/XOR pin recipe turns into SDA
  released for the ACK slot), R1 = counter, R2 = scratch (constants re-LDI'd),
  R3 = next pin value; BNZ costs one cycle taken or not, so the loop-back is
  free in every phase. An ISA finding worth keeping: the earlier record's
  "needs a fifth live value" conclusion holds only for the constant-register
  style; re-materialising constants with `LDI` in the phase slack removes it.
  Reading a bit MSB-first costs seven `SHF RIGHT` (bit 7 of `uio_in` down to
  bit 0) since there is no carry-in or rotate.

    clocks.

    exactly budget+2 cycles by construction (LDI + IN precede the hold, so the
    hold after the IN that sees SCL high is the full budget): Fast t_HIGH 62,
    t_SU;STA 32, t_SU;STO 62; Standard 202, 237, 207; t_LOW and t_HD;STA stay
    exact.

    identical decode, `uo_out` = 0xB4, `stretched_clocks` = 1 (only the read
    clock is a data clock past 2 x t_LOW), t_SU;STA and t_SU;STO never below the
    minimum (Fast 600/1240 ns, Standard 4700/4140 ns in this run), t_HIGH
    never below its budget. Mechanically: 71 of 76 (Fast) / 72 of 76 (Standard)
    SCL intervals are identical to the unstretched run; the remainder are
    exactly the stretched lows and the highs right after them.
    **Determinism claims exclude the stretched interval**: the poll loop lasts
    as long as the peripheral holds SCL, data-dependently by design.
  - *Negative controls (all fail as required)*: (1) firmware with the Sr
    setup WAIT shortened by one cycle, and by half, re-assembled in memory

    the only violation** (Fast 580 ns and 300 ns < 600; Standard 4680 and 2360
    < 4700) while the transfer decodes identically; (2) the DUT's waveform
    compressed 0.9x fails t_LOW and t_SU;STA; (3) the same stretch script against
    the non-polling program is rejected by the model (Fast: "no STOP in
    window"; Standard: "35 data clocks is not a whole number of 9-clock
    bytes") -- the poll is load-bearing; (4) calibration: the model's own
    nominal Sr transfer passes in both grades.
  - *Honest notes.* (a) The peripheral's SCL level is `uio_in` bit 0 (the
    peripheral's own drive); a silicon readback would be the bus level, which is
    the same information once the controller has released SCL, but silicon
    wiring is DR 0008's scope. (b) Measurements carry ~1e-11 ns float noise from
    the sim-time stamps; the bench rounds to 1 ps. (c) The model decodes the

    `docs/environment.md`).
