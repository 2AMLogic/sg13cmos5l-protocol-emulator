- **Claim**: The committed 245-word, table-driven SWD image (issue #500) reads one word of AP memory on the independent model. It sends five requests (0xA5 DPIDR read, 0xB1 SELECT write, 0x8B TAR write, 0x9F posted DRW read, 0xBD RDBUFF read) in 356 SWCLK rises. The pads carry the SELECT payload 0x00000000 and the TAR payload 0x20000004, each as 32 bits LSB first plus even parity, with SWDIO driven for every write-data bit and released for every turnaround and response. The DRW read reports the stale read-buffer value 0xA5A5C3C3; the RDBUFF read reports the addressed word 0xCAFEF00D. The run ends with eight low-data idle clocks and no contention. Each of the five transactions answered WAIT or FAULT ends after three ACK bits and a released turnaround with no data phase; a rejected write leaves the model's SELECT and TAR unchanged and the memory word is never reported. Mutants with a flipped SELECT or TAR write parity bit, a broken ACK-to-write-data handoff, and the earlier connection, turnaround, request-parity, ACK-branch and trailing-idle defects each fail for their own reason.
