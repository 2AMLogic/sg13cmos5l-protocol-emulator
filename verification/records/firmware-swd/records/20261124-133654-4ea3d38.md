The pads carry the SELECT payload 0x00000000 and the TAR payload 0x20000004, each as 32 bits LSB first plus even parity, with SWDIO driven for every write-data bit and released for every turnaround and response. The DRW read reports the stale read-buffer value 0xA5A5C3C3; the RDBUFF read reports the addressed word 0xCAFEF00D. The run ends with eight low-data idle clocks and no contention. Each of the five transactions answered WAIT or FAULT ends after three ACK bits and a released turnaround with no data phase. A write answered with a silent target (ACK 1,1,1) or with 1,0,1 is not accepted as OK: on SELECT and on TAR the probe keeps SWDIO released through the 33 possible data-phase cycles (checked on `uio_oe` at the pads), drives no write data, issues no further request and ends with the eight trailing idle clocks; the model's SELECT and TAR stay unset.
