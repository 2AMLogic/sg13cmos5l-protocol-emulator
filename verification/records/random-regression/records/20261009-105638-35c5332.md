- **Claim**: The seeded constrained-random DUT regression (seed `20261009`,
  issue #93) is **extended to I2C controller read, repeated START and bounded
  peripheral clock stretching on the real core** (issue #104; verification-plan
  section 4's stretching dimension; target-spec rows 8 and 12). A new family
  `i2c_rd` (20 programs at the default budget, after the unchanged 20 UART, 20
  SPI and 20 I2C-write programs) renders the write -> repeated START -> read ->
  controller-NACK -> STOP **polling** program of
  `firmware/tools/gen_i2c_sr.py` (the committed
  `i2c_{fast,std}_sr_poll.asm` instruction stream) with a seeded 7-bit
  address, pointer byte and (peripheral-driven) read byte, at both speed
  grades. The reactive peripheral of `test_firmware_i2c_sr.py`
  (`drive_peripheral_sr`) ACKs, drives the read byte and holds SCL low after 1-3
  of three fixed sites (`pre_sr` = before the repeated START rise, `read_clock`
  = first read clock, `pre_stop` = before the STOP rise) for a seeded hold in
  one of three duration classes (short 8-40, medium 41-200, long 201-400 cycles
  beyond the controller's own t_LOW). Each program is assembled with the DR 0003
  assembler, loaded over the real serial load-phase pins, run on
  `tt_um_2amlogic_protocol_emulator`, and its captured SCL/SDA bus (wired-AND of
  `uio_out` and `uio_in`) is graded by the existing **independent** I2C model
  (`reference_models/i2c.py`, unchanged). **All 20 `i2c_rd` programs PASS** along
  with the 60 pre-existing programs: the model reports no violations, decodes
  address/R-W, the three data bytes (pointer, address-R, read byte) and ACK
  pattern (ACK, ACK, ACK, controller NACK) exactly, a STOP is measured
  (incomplete transfers fail), and the received byte assembled by the core is
  read at its observable result (`uo_out`) and equals the byte the peripheral
  drove. **Determinism is claimed only for non-stretched phases**: every SCL
  interval except the stretched low (whose length must match the scheduled
  hold within 3 cycles) and the high that follows it (bounded between the
  t_HIGH budget and the unstretched value plus one poll pass) is compared
  byte-identical (to the picosecond) against an unstretched run of the same
  grade on the same DUT; the poll/handshake interval is bounded, not asserted
  exact. Controls (mutated programs or captures run on the DUT, graded by the
  same path): per grade, the **non-polling** sibling program under a selected
  stretch schedule (the first generated case with a medium/long `read_clock`
  stretch) is FAILED by the model, while the polling twin on the same schedule
  passes; and a capture truncated to 20 clocks is FAILED (`no STOP in window`).
  The 4 pre-existing mutated-template controls still fail as required.
  **Scope, stated plainly.** The bus is bench-composed from `uio_out` /
  `uio_in` (`uio_oe` is fixed to 0 at the top level): this does **not** verify
  silicon open-drain pad behaviour and decides nothing about the pin plan
  (#94). Deferred, not implied: UART RX, SPI multi-byte bursts under one CS,
  address NACK on the read path, multi-byte reads. No synthesis, timing, area,
  gate-level or silicon result is claimed; this is an Icarus RTL simulation.
